Akeneo est désormais reconnu comme l’un des meilleurs PIM (Product Information Manager) du monde.
Mais ce n’est pas seulement le meilleur, c’est aussi un logiciel Open-Source que vous pouvez utiliser gratuitement !

Splash Bundle for Akeneo offre un accès complet à votre catalogue de produits pour vos autres applications, telles que le commerce électronique et l'ERP.

### Gérez tout votre catalogue de produits en un seul endroit

Connecté à votre compte Splash, Akeneo gérera toutes les informations relatives à vos produits sur une interface unique, confortable et flexible.

* Informations ERP
* Caractéristiques
* Données SEO
* Photos des produits
* Variantes de produits

### Splash connectera tous les champs

Grâce à son architecture intelligente, Splash est capable de synchroniser tous les types d'attributs proposés par Akeneo.

Même les prix, les mesures et les images !

### Compatibilité

| Akeneo PIM          | PHP   | Branche du bundle |
|---------------------|-------|-------------------|
| 7.0                 | 8.1   | 7.0               |
| 2026.x              | 8.3   | 7.0               |
| 4.0 & 5.0           | 7.3+  | 5.0               |

Installez le bundle avec Composer, la bonne version est sélectionnée selon votre version d'Akeneo :

```bash
composer require splash/akeneo-bundle
```
